# 使用指南

## 日常使用

- 右上角 **＋添加**：默认直接填写任务名称与说明。
- 点击复选框或任务名称：完成 / 撤销完成。
- 拖动空白处：移动窗口。
- 拖动右下角手柄：整体缩放。内容越长、任务越多，窗口会自动调整基础尺寸。
- **精简 / 展开**：隐藏或显示说明、透明度和操作提示。
- 展开模式可调透明度；窗口跟随系统深浅色主题。

任务数据每次操作后保存。其他工具用约定格式更新 `tasks.json` 后，应用约一秒内刷新。

## 关闭与重新打开

点击关闭按钮只隐藏窗口；应用继续留在菜单栏。菜单栏 `☑ 已完成/总数` →「显示今日待办」可重新显示。双击应用也能重新显示窗口。

只有菜单栏选择「退出悬浮待办」才会退出程序并停止提醒。

## 提醒

菜单栏 →「设置」可更改时间、时区，或关闭提醒。默认17:00，时区取首次运行时的系统时区。更换时区后需手动更新设置。

应用运行时约15秒检查一次，每个清单日期至多提醒一次；空清单不提醒。当日提醒时间已过再打开应用，若有任务且尚未提醒，会补提醒。电脑休眠时不唤醒系统，恢复后检查。不内置独立后台服务或自动开机启动。

## 跨日与历史

首次启动、每天跨日或从休眠恢复后，应用检测清单日期：

1. 把上一份清单保存到 `history/YYYY-MM-DD.json`。
2. 保留未完成任务到新一天；已完成任务留在历史快照。
3. 新一天重置提醒标记。

不会生成没有使用应用的每个空白日期。未来日期的数据不会自动往回改。历史目前通过菜单栏「打开数据与历史记录」查看，还没有应用内历史面板。

## 复盘

点击「进度 / 复盘」查看完成与未完成清单，并围绕实际成果、阻碍、下一步补记。可以复制到笔记、工作日志或 Codex。

当前版本不保存你对复盘问题的回答；下一阶段会加入应用内填写与历史回看。勾选仅表示用户自报完成，不表示外部系统已验收。

## 备份、升级、卸载

备份整个 `~/Library/Application Support/FloatingTodo/`。升级前退出旧版，替换应用，再打开；新应用会继续读取原数据。不要把备份直接提交到公开仓库。

卸载只需退出并移除应用。数据目录保留，便于重装恢复；如果要清除个人数据，请先备份，再由自己删除该目录。

## 常见问题

**双击后没窗口？** 先从菜单栏重新显示；如果刚升级，需退出仍在运行的旧版本再打开。

**看到无法验证开发者？** 首版还没有 Developer ID 公证。仅在确认来源可信后，按照 [Apple 官方说明](https://support.apple.com/102445) 在系统设置中允许这一个应用。不要关闭整台电脑的 Gatekeeper。

**没有提醒？** 检查应用是否运行、清单是否为空、设置时区是否正确，以及当天是否已经提醒过。提醒不会在关机时运行。

**数据格式错误？** 应用保留原文件，不会静默覆盖。备份后检查 JSON，或提交移除了个人任务的最小复现。
